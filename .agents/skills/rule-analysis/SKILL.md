# Rule Analysis — 근거 중심 정책 해석

## 순서
1. 실제로 제공된 원본 규정과 참고문서를 구분하고 적용 범위, 버전, 효력을 확인한다.
2. 각 판정 조건을 **원문 위치, 적용 대상, 연산, 임계값, 예외, 우선순위**로 구조화한다.
3. `미만/이하`, `초과/이상`, 날짜 포함 여부, 단위, 복수 조건의 AND/OR를 확인한다.
4. 서로 충돌하거나 빠진 문장은 '확인 필요'로 표시하고 담당자에게 우선 질문한다.
5. 판정마다 **사용한 입력값 → 적용 조항·예외 → 핵심 중간 판정 → 최종 판정**을 추적 가능하게 한다.
6. 경계의 직전/정확히 같음/직후, 예외 중첩, 누락 사례를 **다른 테스트 경로**와 대조한다. 사용한 문구와 실제 테스트 결과를 기록한다.
7. 각 결과에 출처 위치를 붙이고 `확인됨/잠정(가정)/미확인`을 구분한다. 애매한 조건은 확정 판정하지 않는다.

## 주의
- 공개 일반 상식으로 제공된 업무 규정을 임의 대체하지 않는다.
- 확인되지 않은 예외를 만들어내거나 출처 없는 확신을 표시하지 않는다.
- PDF 변환 등의 별도 도구는 제공 환경의 기능과 사용 허가를 먼저 확인한다.
