# Data Audit — 데이터와 계산 검증

## 순서
1. 원본을 보존하고 파일 종류, 인코딩, 구분자, 컬럼명, 데이터 타입, 건수를 확인한다.
2. 값의 의미, 단위, 시간대, 기본키, 조인 키, 빈 값과 특수값 정의를 파악한다.
3. 결측, 중복, 유효 범위, 이상치, 날짜 파싱, 숫자 정밀도, 조인 다대다 증폭 가능성을 점검한다.
4. 요구사항이 정의한 집계 구간, 분모, 필터, 예외와 경계값을 확인한다. 뜻이 모호하면 임의 결정하지 않는다.
5. 핵심 산식의 **분자·분모, 필터 전후 건수, 그룹별 소계, 단위와 반올림 기준**을 남긴다. 원본 값이나 열을 읽지 못하면 값을 지어내지 않는다.
6. 주요 결과는 서로 다른 경로로 **독립 검산**한다(예: 합계↔그룹별 소계, SQL↔Python, 소규모 표본 수작업 계산). 단순 재실행은 독립 검산이 아니다.
7. 결과를 `확인됨/잠정/미확인`으로 구분하고, 데이터 문제와 영향을 받는 결과, 해결하지 못한 차이를 짧게 보고한다. 표본 검증과 전체 검증을 혼동하지 않는다.

## 운영 원칙
- 가능하면 제공된 로컬 Python, SQL 및 기존 라이브러리를 사용한다. 불필요한 패키지를 추가하지 않는다.
- 원시 데이터나 비밀정보를 외부 MCP 또는 API로 전송하지 않는다.
- 전체 행을 대화에 덤프하지 말고 건수, 컬럼 목록, 필요한 범위의 예시만 제시한다.
- 누락 데이터와 자료 오류를 0으로 채웠다는 가정을 숨기지 않는다.
