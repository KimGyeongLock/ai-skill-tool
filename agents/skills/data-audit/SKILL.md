# Data Audit
1. 데이터 파일 수, 전체 행 수, 컬럼 및 자료형, 기본키, 조인 키, 단위와 결측 표시법을 **실제 파일**로 파악한다.
2. 누락, 중복, 타입 변환, 시간대, 비정상 범위, 조인 증폭, 정렬/동률, 표본 편향을 점검한다.
3. 집계/판정/최적화 지표의 정의를 명세와 대조한다. **분자·분모·단위·필터 전후 건수**와 해석을 확인한다.
4. 수치 결과는 소계↔합계, 별도 쿼리, 표본 손계산 등 독립 경로로 확인한다. 전체 검증과 표본 검증을 구분한다.
5. 데이터 결함이 어떤 결과에 영향을 미치는지 보고한다. 원본은 수정하지 않고, 외부 서비스로 전송하지 않는다.
