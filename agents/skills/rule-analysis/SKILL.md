# Rule Analysis
1. 공식 정책/참고 문서의 적용 범위, 버전, 우선순위와 근거 위치를 파악한다.
2. 조항별 대상, 조건, 임계값, AND/OR, 예외와 예외 간 우선순위를 구조화한다.
3. `미만/이하/초과/이상`, 날짜 범위, 단위, 누락 값의 처리 등 결과에 영향을 주는 모호한 조건을 질문으로 분리한다.
4. 판정의 입력값→관련 조항→예외 적용→중간 판정→최종 판정을 추적 가능하게 기록한다.
5. 경계의 전/일치/후, 충돌, 예외 중첩, 누락 입력을 실제로 테스트한다. 근거가 없는 판정은 '미확인'으로 표시한다.
6. 문서의 업무 목적과 더 단순한 대안을 검토하되 과잉 설계와 불필요한 쓰기 보호/기능을 추가하지 않는다.
